# **App Name**: MirrorFolio

## Core Features:

- Content Replication: Mirror the layout and content structure of the reference portfolio, using placeholder text and images.
- Color Scheme Cloning: Replicate the precise color palette used in the original design.
- Typography Duplication: Match and implement the fonts and typographic styles to replicate the original site’s visual hierarchy.
- Responsive Layout: Implement a responsive layout that adapts to various screen sizes, ensuring the portfolio looks great on all devices, with the AI tool verifying that specific elements and their styling do not overflow the container
- Interactive Elements: Duplicate any interactive elements such as hover effects or transitions present in the original portfolio to enhance user engagement.
- Navigation Structure: Mirror the navigation structure, enabling users to browse the placeholder content smoothly.

## Style Guidelines:

- Primary color: Dark slate blue (#434A54) for a professional, muted tone.
- Background color: Off-white (#F9FAFB), near the primary in hue, for a clean, subtle backdrop.
- Accent color: Muted sky blue (#748FFC) to provide contrast without overpowering the palette.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern, machined, neutral feel.
- Grid-based layout to ensure consistency and alignment across all sections.
- Minimal, outline-style icons for a clean and modern look.
- Subtle fade-in animations on scroll to create a smooth user experience.
